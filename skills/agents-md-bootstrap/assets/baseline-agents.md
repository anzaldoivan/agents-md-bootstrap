# Reusable policy baseline

This asset is an adaptation template, not repository evidence or an instruction file automatically applied by a client. Select applicable policies for the target repository; omit this introduction from generated instructions. A user-supplied personal baseline replaces these defaults. Do not claim these preferences were discovered in code.

## Working policy

- Preserve existing user work and keep changes within the requested task.
- Locate the canonical implementation, configuration, or documentation before changing behavior. Update its owner rather than maintaining competing copies of the same fact.
- Inspect relevant local instructions before editing their scope. Surface unresolved conflicts that materially affect the task.
- Prefer the smallest coherent change; avoid unrelated refactors and speculative scaffolding.
- Run checks appropriate to changed behavior when available. Report what ran, what failed, and what could not be verified.
- Keep credentials, private data, and machine-specific personal settings out of shared artifacts.

## Adoption

Keep only rules that change likely agent decisions and are not already reliably supplied by the target environment. Add repository-specific pointers only after inspecting their targets. A selected policy is a preference, not evidence of existing project practice. Record adoption rationale in the delivery summary, not as a permanent evidence ledger in `AGENTS.md`.
